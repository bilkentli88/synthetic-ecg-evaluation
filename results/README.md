# Reported results

The CSV files contain seed-level metrics and three-seed summaries for the experiments reported in the study.

- `mitbih_seed_results.csv`: 3 models × 3 seeds
- `mitbih_summary.csv`: mean and sample standard deviation across seeds
- `svdb_seed_results.csv`: 3 models × 3 seeds
- `svdb_summary.csv`: mean and sample standard deviation across seeds

`DistributionalMMD2` is a discrepancy measure, so lower values indicate closer distributional agreement under the specified kernel protocol.
